# GitHub Setup & 6-Day Commit Plan

- **Recommended Repo Name:** `Weather-Forecast-Alert-Application`
- **Description:** Python weather monitoring and risk-alert engine with SQLite persistence, configurable threshold rules, FastAPI endpoints, and Matplotlib forecast charts.
- **Tags:** `python`, `weather-api`, `alert-system`, `fastapi`, `sqlite`, `matplotlib`

## 6-Day Commit Plan
1. **Day 1:** Repo setup, `.env.example`, SQLite schema (`db/schema.sql`), and simulation JSON.
2. **Day 2:** Ingestion and database persistence (`src/ingest.py`).
3. **Day 3:** Risk alert rule engine (`src/rules.py`) for rain, heatwave, wind, and UV.
4. **Day 4:** 7-day temperature and rainfall Matplotlib charts (`src/plots.py`).
5. **Day 5:** FastAPI endpoints (`api/app.py`) and Streamlit/Next.js UI.
6. **Day 6:** Golden unit tests, `README.md`, and interview prep docs.
